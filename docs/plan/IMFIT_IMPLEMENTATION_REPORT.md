**Implemented mechanics:** authority stores a compact consecutive **lifecycle-only receipt range** bound to the exact identity; ordinary validators/calls stay strict, and all non-lifecycle controls/credential mutations/restore/identity changes/poison/shutdown break continuity. Valid controls carry only the explicitly retained handle's original immutable credential to their own next receipt. Callback captures one call snapshot once, claims it under the fence, and cannot combine a newer flow context with an older request. In-flight callback is invalidated, never silently rebound. Current authentication/lease survives job-only pause/resume; foreground no longer reloads legacy storage or manufactures an identity. Paused callback/import publication cannot schedule refresh. A transient refresh error can resume only its exact previously scheduled credential context (not current-owner lookup). No HTTP in authority/storage fence.

Android uses one ordered mailbox, no isActive prefilter or independent racing callback launches; events synchronously capture original operation and await same-authority validation. Observer registration waits for bootstrap then captures a **fresh lifecycle observation**, including initial CREATED/paused state; it never carries bootstrap provenance across restore. Binding barrier awaits registration readiness before queued callbacks; cancellation/close cancels waiters. Close drains the shared authority first, cancels work, then joins owned observer removal on Main **outside** the authority. Tests include actual ProcessLifecycleOwner attach/remove, but no claim of real browser return/OS lifecycle generation is made from registry tests.
